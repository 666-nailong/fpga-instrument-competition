# FPGA 纯硬件多音色电子乐器资料归档

本仓库保存比赛材料的隐私处理副本及 FSR402B 脚踏板 3D 打印设计。

## 目录

- `比赛材料/`：技术文档、海报、实物照片、最新最终版演示视频（仅一份）、全部代码压缩包及脱敏授权书。
- `源代码/FPGA_Instrument_r20/`：由提交代码包解压得到的 FPGA/HMI 源文件及位流。
- `脚踏板3D打印/`：底座和压板的 STEP/STL、参数化建模源码、尺寸装配图、爆炸图、打印装配说明及 ZIP 打印包。

## 隐私处理

授权书中的手写成员信息、签名、队伍编号和日期已在上传副本中永久遮除，并重新生成 PDF；此副本仅供资料归档，不能作为可签署或可提交的授权文件。PDF 文档元数据和照片元数据已清理。未上传本机目录历史、缓存、Git 历史或个人提交身份。本地原始材料保持原样。

最新视频检查包括片头逐秒画面核对、全片抽帧及本地自动语音转写，未发现明确的姓名或学校信息；自动转写与抽帧不能代替逐帧人工审查。所有视频使用 Git LFS 保存，克隆后需执行 `git lfs pull` 下载完整视频。

脚踏板文件为设计归档，打印、装配、传感器标定与实机验证状态以工程证据为准。
